SMS Spam Detector

Clean spam analysis for your messages

Paste an SMS-style message, then get a crisp prediction whether it is spam or safe.

Check an SMS message

The text is sent only to the local classifier backend and never shared with external AI services.

How it works

The frontend sends JSON with text to /api/predict. The backend returns the classification result.

Why this app

This is a focused SMS spam classifier, not a generic AI chat or content generator.

Ready to use

Run the Flask backend and open this page in your browser. The app is designed to be fast, simple, and readable.
